# Tutorial Preparation

To prepare for my tutorial, please clone this repository: [https://github.com/snowjademusic/PLP-AssemblyTutorial](https://github.com/snowjademusic/PLP-AssemblyTutorial)

then,

1. follow the Instructions for your architecture
2. Verify that building the Hello, World! script for your architecture works (All steps should be explained)

I could only test the Linux x86-64 and mac x86-64 version. Should the instructions for your architecture not work, please contact me @ [shadisamuelthierry.vandeventer@uzh.ch](shadisamuelthierry.vandeventer@uzh.ch)

## Optional VS Code extensions

If you're using VS code as your main IDE, I can reccommend the [NASM Language Support](https://marketplace.visualstudio.com/items?itemName=doinkythederp.nasm-language-support) Extension if you're on an x86_64 cpu. For arm cpu's, maybe try [Assembly for ARM64](https://marketplace.visualstudio.com/items?itemName=MKornelsen.vscode-arm64)
